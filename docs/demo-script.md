# 演示脚本

目标时长 8～12 分钟。演示文件必须是允许使用的非敏感文本型 PDF。

1. 打开系统状态页，展示 API、数据库、Redis 和 Qdrant 健康。
2. 上传 PDF，记录返回的任务 ID。
3. 展示 `parse → clean → structure → chunk → persist → index` 阶段推进。
4. 打开书籍，浏览章节、页码和原文 Chunk。
5. 指定书籍和章节提问，打开引用并核对原文与页码。
6. 打开检索调试，展示 Dense、Sparse、RRF、Rerank 的排名和耗时。
7. 提出一个原文没有答案的问题，展示证据不足处理。
8. 生成结构化摘要、知识点和复习题，展示引用约束。
9. 在评测中心运行固定数据集，展示指标和消融报告。
10. 使用预先准备的可重试失败案例，展示从失败阶段恢复且不重复成功阶段。

演示前执行后端测试、前端 lint/build，并确认模型、缓存和网络条件。当前仓库的两页试运行评测集只能证明管线可运行，不应表述为生产质量结果。
