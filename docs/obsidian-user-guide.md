# 图片资产与 Obsidian 使用指南

当前后端及前端代码已接入，本地回归、构建、浏览器与导出文件检查已通过；PostgreSQL/Compose 和 Obsidian 客户端显示检查仍待完成。详见 [验收记录](obsidian-acceptance-report.md)。

## 1. 连接后端

服务端需要配置 `BOOKDISTILL_API_KEY`。在网页顶部点击“配置 Key 与模型”，填写后端访问 Key，然后点击“仅连接后端”。图片预览和导出无需配置生成模型。

后端地址可在“系统状态”页设置。前后端地址不同时，服务端 `BOOKDISTILL_CORS_ORIGINS` 需要允许当前网页来源。访问 Key 仅保存在当前浏览器会话，图片和 ZIP 请求通过请求头携带它。

## 2. 查看书中图片

1. 在“书籍库”打开一本书。
2. 点击“书中图片”。列表显示 PDF 物理页号、图片尺寸与资产 ID，每页最多显示 24 张。
3. 点击“预览与下载”，查看大图；点击“下载原图”保存图片文件。
4. 处理或重处理后，可点击“刷新”重新读取清单。

图片在文本解析前独立保存。书籍文本处理失败时仍可查看已保存图片，失败原因可在“系统状态”的后台任务中查看。扫描页目前不支持 OCR；纯文字或矢量图页面可能没有嵌入位图。

## 3. 独立上传图片

打开侧栏“图片资产”，选择静态 PNG、JPEG 或 WebP，然后点击“上传并保存”。成功后显示保存 ID，并刷新分页列表。列表中的图片可预览和下载。

独立图片不创建书籍，不参与文本检索。服务器验证真实格式、完整性和容量，拒绝动画/多帧、损坏及超限图片。默认文件上限为 20 MiB、像素上限为 4000 万、单边上限为 16384，可由服务端配置调整。

独立上传图片在此页单独下载；按书籍生成的 ZIP 包含该书 PDF 的图片资产。

## 4. 导出到 Obsidian

1. 打开书籍详情，找到“导出到 Obsidian”面板。
2. 按需勾选“包含原 PDF 与页链接”；默认为不包含。
3. 如需导出摘要、知识点、题目或观点比较，填写已保存产物的完整 UUID。可用换行、逗号或分号分隔，重复 ID 会合并，最多 100 个不同 ID。
4. 点击“下载 Obsidian ZIP”，等待完整 ZIP 生成；成功后在浏览器下载列表查看 `bookdistill-<book_id>.zip`。
5. 将 ZIP 解压到 Obsidian vault 根目录，打开 `BookDistill/Books/<book_id>/index.md`。

导出需要已经保存的可靠文本与章节。没有文本快照的扫描书籍不能生成完整 ZIP，图片仍可单独下载。ZIP 内容包括章节 Markdown、图片、所选产物、manifest，以及勾选时的原 PDF。

PDF 页链接使用物理页号。未勾选原 PDF 时，不生成指向 PDF 的链接。跨书产物保留全部书籍来源、引用和页序，只为本次打包的书籍生成 PDF 链接。

### 保存产物 ID 与版本

在“蒸馏工作台”生成成功后，结果下方显示“已保存产物 ID”。点击文本框会选中完整 ID，复制后填写到书籍详情导出面板。已有 API 保存的其他产物也可使用其 ID。

人工编辑保存会创建新的产物 ID。导出使用填写 ID 对应的内容、版本和编辑状态；不会自动选择最新版本、重新生成内容或调用模型。产物中保留完整保存内容和全部来源信息。留空时不导出生成产物。

### 重复导出

应用输出使用稳定 ID 文件名。重新解压到相同 vault 会覆盖对应的导出文件；自写笔记请放在 `BookDistill/` 目录外。更换产物选择后，解压不会自动删除以前留下的产物文件。

## 5. 常见提示

| 提示 | 处理方式 |
|---|---|
| 访问 Key 缺失或不正确 | 点击“配置访问 Key”，填写后端访问 Key，再重试 |
| 服务器未配置访问 Key | 在服务端设置 `BOOKDISTILL_API_KEY` 后重启服务 |
| 无法连接后端 | 在“系统状态”核对 API 地址、网络及跨域配置 |
| 文本和章节尚未就绪 | 查看后台任务；已保存图片仍可访问 |
| 指定产物不存在或与本书无关 | 核对完整保存 ID 及产物来源 |
| 保存产物引用不完整 | 核对保存内容及来源；不能通过导出补写引用 |
| 导出期间内容变化 | 等处理完成后重新下载 ZIP |
| 图片格式、容量或完整性不符合要求 | 选择有效且较小的静态 PNG/JPEG/WebP |
| 下载已开始但没有看到文件 | 查看浏览器下载列表及下载限制 |

错误可能带追踪 ID，排查服务器问题时可据此查找日志。格式细节见 [冻结契约](obsidian-v1-contract.md) 和 [调用示例](../examples/obsidian-v1/export-format.md)。
