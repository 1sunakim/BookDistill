- 处理流程为 `parse → clean → structure → chunk → persist → index`。

### 人工判定口径

- **通过：** 核心事实与原文一致，重要限定没有丢失；题目可由证据回答；引用可回到支持该结论的原文。
- **部分通过：** 主体正确，但存在遗漏、表述过度概括、题目质量一般或引用只能部分支持。
- **不通过：** 有事实错误、无依据断言、关键内容漏失、题目答案与材料冲突，或引用无法支持结论。

问题可按发生位置归类：原文或章节异常归文档处理；所需证据未召回归检索；证据正确但生成结果失真归生成。不要仅依据合法的 citation ID 判定语义引用正确。
