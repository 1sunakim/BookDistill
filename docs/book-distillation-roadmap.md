# 书本蒸馏首版技术路线与边界

> 状态：规划稿。依据 2026-10-12 的仓库 `main`（`138a16a`）代码与文档；未据此宣称运行质量已达标。

## 1. 现状与目标

现有链路为：文本型 PDF 上传 → `document.process` 六阶段（parse、clean、structure、chunk、persist、index）→ 混合检索与 Evidence → 带引用的摘要、知识点、题目和观点比较 → 产物持久化。后端已有同步与任务接口、结构化输出校验、引用 ID 校验和版本化产物；前端已有单书蒸馏入口。

首版目标是让一本文本型 PDF 可以形成**可检查的章节及全书蒸馏产物**：每条关键结论能回到原文页码，处理范围和遗漏可见，失败可重试，人工可审阅。生成成功仅代表流程成功，不代表内容质量合格。

## 2. 三条边界

| 工作线 | 负责 | 不负责 |
| --- | --- | --- |
| 文件读取扩展（document_processing） | 文件识别与校验、解析/OCR、版面与章节、标准 `ParsedDocument → Chapter → Chunk`、原文位置映射；按格式记录解析版本和质量标记 | Prompt、蒸馏内容、模型调用、检索排序 |
| 蒸馏功能完善（generation 与产品界面） | 从指定书/章节组织 Evidence、分层摘要、知识点/题目、引用及来源回查、任务/产物版本、人工审阅 | 直接读取原始文件、生成页码、修改索引或解析结果 |
| 检索与评测（retrieval/evaluation） | 证据召回与排序、范围过滤、覆盖率和质量指标、失败归因 | 解析文件格式或替生成结果背书 |

跨模块只传版本化协议对象。增加格式时，优先产出与 PDF 一致的 `ParsedDocument`、`Chapter`、`Chunk`；如果来源定位语义改变，先更新协议和消费者，再接入解析器。不得把 DOCX/EPUB 的段落编号伪装成 PDF 页码。

## 3. 实施顺序

### 阶段 A：基线与可复现样本

1. 固定 2–3 本有授权的文本型 PDF，覆盖中文、英文和复杂目录；保存解析、章节、Chunk、检索与模型配置版本。
2. 跑现有测试和端到端链路，记录缺失证据、章节错误、生成失真、引用不支持四类问题。先解决阻断运行的环境问题。
3. 建立人工抽查集：按章节记录必需主题、关键事实、页码和可接受的摘要/问题要求。现有 2026-09-29 验证报告中的召回分数属于历史候选结果，应重新测量。

### 阶段 B：首版蒸馏闭环（仅文本型 PDF）

1. 新增“以书籍/章节为输入的证据编排”应用层：验证书籍 ready、读取章节和 Chunk，以章节覆盖为优先组织证据；普通 query 检索用于主题补充，不把一次 top-k 结果当作全书内容。
2. 长书采用 `Chunk/小节 → 章节 → 全书` 分层处理。每级记录输入 Chunk/Evidence ID、范围、模型/Prompt 版本、时间、任务 ID 和父子关系；超出预算时分批执行，不静默截断。
3. 沿用现有 `DistillationService`、LLM Gateway、结构化 Schema 和引用校验。新增覆盖率与范围校验：不得跨书/章引用，不得把只有合法 ID 的引用当作语义支持。
4. 使用现有任务系统运行长任务，阶段检查点与稳定幂等键允许重试；持久化中间章节产物和最终版本，失败保留已完成部分及原因。
5. 前端支持书/章节、产物类型和参数选择；显示阶段进度、逐条引用和原文跳转、覆盖范围/未覆盖章节、模型版本、编辑版本与重新生成入口。优先让摘要可完整审阅，再扩展知识点与题目体验。

### 阶段 C：质量门禁

1. 解析：章节与页码映射抽查；检索：必需证据召回与丢失位置；生成：事实忠实度、摘要覆盖率、知识点准确率、题目答案支持率和引用准确率。
2. 每个结论保留“输入正确但生成错误”与“输入缺失”区分；人工复核不能被 Schema 通过率取代。
3. 用同一批真实书对 demo 和目标模型分别验收。demo 仅证明工程链路；目标模型必须有脱敏运行记录与人工判定。发布阈值沿用现有验收文档，未达到时明确标注试验状态。

### 阶段 D：文件读取扩展（独立工作线）

1. 先补混合/扫描 PDF 的按页 OCR：只处理缺失有效文本层的页，保留页序号、OCR 来源、置信度和可重试失败。
2. 再评估 EPUB、DOCX、Markdown/TXT 的优先级。每种格式有独立 validator、parser 和测试样本；统一输出标准文档协议。新增“位置锚点”能力时保持旧 PDF 引用兼容。
3. 新格式接入的完成条件是解析、章节、Chunk、来源回查及重建全部通过；不能仅以可上传或抽出文本为完成。

## 4. 明确暂缓

首版不做默认联网补知识、知识图谱、视频生成、复杂 Agent、多租户；不把图片资产上传等同书籍 OCR；不把多书观点比较作为单书首版的阻断项。扫描 PDF、EPUB、DOCX 等格式在阶段 D 独立交付。

## 5. 首版验收定义

- 任一本样本书可以从 ready 状态发起章节蒸馏及全书蒸馏，进度、失败原因与重试可见。
- 全书产物列出覆盖章节和未覆盖章节；每条关键结论的证据可定位到原文，且属于选定范围。
- 模型配置、Prompt、解析/Chunk 版本和输入证据可追溯；人工修改保存为新版本。
- 真实书人工抽查集达到现有 `docs/generation-acceptance.md` 门禁，并记录检索门禁结果。门禁未通过时不标记为质量合格。
